Place your reference background images in this folder so the Next.js app can serve them as static assets.

Current expected filenames:
- ai-brain-bg.jpg
- ai-signal-wave.jpg
- ai-code-overlay.jpg

You can replace `ai-brain-bg.jpg` with any image you prefer by updating the CSS variable `--bg-image` in `app/globals.css`.

Example:
```css
:root {
  --bg-image: url('/images/ai-signal-wave.jpg');
}
```
