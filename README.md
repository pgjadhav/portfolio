# Prashant Jadhav Portfolio Website

A modern Data Science and AI/ML portfolio built with Next.js, Tailwind CSS, GSAP, and React Three Fiber.

## Project Overview

- **Responsive Design**: Fully responsive portfolio layout with glassy UI effects
- **Advanced Animations**: GSAP-powered scroll-triggered animations and staggered reveals
- **3D Elements**: Interactive 3D character model and tech stack spheres using React Three Fiber
- **Project Carousel**: Smooth carousel navigation for projects with dots and arrows
- **Custom Cursor**: Enhanced cursor with hover states and smooth following
- **Loading Screen**: Animated loading screen with progress bar and letter animations
- **Sections**: Hero, About, Experience, Projects, Skills, Education, Contact
- **Modal**: Detailed project case study modal
- **Dark/Light Theme**: Toggle between themes with localStorage persistence

## Features

- **Hero Section**: Split name animation, scroll-down indicator, 3D character model
- **About**: Expertise items with hover effects, staggered text reveals
- **Experience**: Timeline with animated entries
- **Projects**: Carousel with navigation controls and indicators
- **Skills**: Progress bars and 3D tech stack visualization
- **Education**: Card grid with hover animations
- **Contact**: Functional contact form with mailto integration

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS with custom utilities
- **Animations**: GSAP with ScrollTrigger
- **3D Graphics**: React Three Fiber and Drei
- **TypeScript**: Full type safety
- **Icons**: Custom CSS and emoji

## Commands

- `npm install` — install dependencies
- `npm run dev` — run development server
- `npm run build` — build for production
- `npm start` — run the production build

## Notes

- Update personal details in `app/page.tsx` as needed
- 3D models are lightweight and optimized for performance
- Animations are GPU-accelerated for smooth experience
- Site is ready for deployment to Vercel, Netlify, or any static host

## Run the Project

```bash
npm run dev -- --hostname 0.0.0.0 --port 3000
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
